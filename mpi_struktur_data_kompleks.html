Struktur Data Tree (Pohon)

Tree adalah struktur data non-linear yang menggambarkan hubungan hierarkis antar elemen (dinamakan Node). Elemen paling atas disebut Root, dan elemen tanpa cabang disebut Leaf (Daun).

  • Root: Simpul awal/teratas tanpa parent (A).
  • Parent & Child: A adalah parent dari B dan C.
  • Leaf Node: Simpul paling ujung tanpa child (D, E, C).
  • Binary Tree: Tree yang setiap simpulnya maksimal memiliki 2 child.
Tahukah Kamu?
Sistem direktori file di komputer kamu (seperti C:/Users/Documents/) disusun menggunakan struktur data Tree!

Struktur Data Graph (Graf)

Graph terdiri dari kumpulan titik dinamakan Vertex (V) dan garis penghubung dinamakan Edge (E). Berbeda dengan Tree, Graph tidak memiliki konsep Root dan dapat membentuk sirkel/loop.

Jenis-jenis Graph:
  • Directed Graph: Sisi memiliki arah panah tertentu.
  • Undirected Graph: Sisi berlaku dua arah seimbang.
  • Weighted Graph: Memiliki bobot/nilai pada jalurnya (contoh: jarak km pada GPS).
Fakta Menarik:
Jaringan pertemanan di Instagram dan Facebook diproses menggunakan Weighted Directed Graph!

Hash Table

Hash Table memetakan kunci (Key) ke nilai (Value) menggunakan Hash Function. Memungkinkan pencarian data sangat cepat dalam waktu rata-rata O(1).

Proses Kerja: Key → [ Hash Function ] → Index Array → Value Data.
Info Penting - Kunci Tabrakan (Collision):
Jika dua key menghasilkan indeks hash yang sama, terjadi Collision. Solusinya menggunakan metode Chaining (Linked list) atau Open Addressing.

Trie (Prefix Tree)

Trie adalah struktur data berbentuk pohon khusus untuk menyimpan sekumpulan string/karakter secara efisien. Sangat ideal untuk pencarian berbasis Awalan (Prefix).

Contoh Menyimpan Kata: "CAT", "CAR", "DOG"
Root → [C] → [A] → [T / R] | [D] → [O] → [G]
Tahukah Kamu?
Fitur Autocomplete Google dan Spell Checker di Microsoft Word menggunakan struktur data Trie!

AVL Tree (Self-Balancing Tree)

AVL Tree adalah Binary Search Tree (BST) yang mampu menyeimbangkan dirinya sendiri secara otomatis sehingga selisih tinggi sub-tree kiri dan kanan (Balance Factor) maksimal 1.

Balance Factor Formula:
Balance Factor = Height(Left Subtree) - Height(Right Subtree)

Jika BF bernilai > 1 atau < -1, maka dilakukan **Rotasi** (Single Rotation / Double Rotation).

Keunggulan AVL Tree:
Mencegah pohon berubah menjadi miring seperti Linked List, menjamin kompleksitas pencarian tetap optimal O(log n).
